# assets/lottery/

Local, owner-supplied images for the home-page lottery panel.

- Drop **licensed** badge and poster images here (JPG/PNG/SVG).
- Reference them from `data/lottery.json` by relative path, e.g.
  `"posterSlot": "assets/lottery/current-poster.jpg"`.
- **Local files only.** No external URLs, no trademarked lottery logos, no
  scraped posters — see `data/README.md`.

If this folder is empty (the default), the panel draws its own trademark-free
SVG badge and simply omits the poster. Nothing to do to ship.
